# Electricity Demand Forecasting Data And Results
This repository stores the data and results required for electricity demand forecasting.
# DyXGBoost-LightGBM Ensemble (DLE) Model
This repository contains the experimental data and corresponding experimental program codes in the paper "Electric Vehicle Charging Behavior Prediction Model Based on DyXGBoost-LightGBM Ensemble".
# Dataset Description
Datasets include: Experiment 1: the California Institute of Technology (Caltech) dataset Experiment 2: the Jet Propulsion Laboratory (JPL) dataset.
# Data Structure
The data includes detailed electric vehicle charging behavior data such as stationID, spaceID, userID, kWhRequested, Requested_parking_time, etc.
# usage
This dataset supports research on predicting electric vehicle charging behavior. Caltech and JPL data provide stable and reliable input for algorithm validation.
